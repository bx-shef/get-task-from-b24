## Цель

Сетевой обработчик, который ловит создание задачи на портале клиента Битрикс24,
проверяет критерии и заводит задачу в нашем Битрикс24 + шлёт сигнал в Telegram.
Порталов клиентов — **20–30**, список в переменных окружения.

Критерии, перенос полей и поведение при ошибках — [`PROCESSING.md`](PROCESSING.md).

## Что мешает запуску

- ⛔ **Не выбран стек** — без него нет ни CI, ни кода.
- ⛔ **Домен обработчика.** В задании указан `client-bank-alfa-by.bx-shef.by` — домен
  соседнего проекта; похоже на опечатку. Локальное приложение у клиента заводится

  не меняется: нужна БД или иное перечитываемое хранилище
  ([`CLIENT_APP.md`](CLIENT_APP.md) — таблица вариантов).
- ⬜ Остальные открытые вопросы — в конце [`PROCESSING.md`](PROCESSING.md).
- ⬜ Доступы: `client_id`/`client_secret` первого портала-клиента, id «особого»
  исполнителя, URL вебхука нашего Б24, токен Telegram-бота и chat id.
