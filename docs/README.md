## Правила

- Каждый документ несёт `> Last reviewed: YYYY-MM-DD` строкой под заголовком; дату
  бампим при содержательной правке. Наличие штампа проверяет тест `tests/mdReviewStamp.test.ts`.
- **Исключение — [`spec/`](spec/).** Это внешний документ, положенный как есть; он несёт
  собственную версию и дату, и править его нельзя: наши выводы из него живут в
  [`PRODUCT.md`](PRODUCT.md) и [`ROADMAP.md`](ROADMAP.md). Тест штампов обходит `docs/`
  рекурсивно и держит `spec` единственным исключением списком — чтобы следующий
  подкаталог не оказался непроверенным молча.
- **Один факт — одно место.** Нужен во втором документе — ставим ссылку, а не копию:
  расходятся именно продублированные утверждения, и замечают это случайно.
