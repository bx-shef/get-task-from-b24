# Система работы с обращениями — пакет документации

Дата фиксации: 01.08.2026. Для передачи проектной команде.

## Состав

1. **spec-ticketing.md** — спецификация v1.3. Главный документ: архитектура, контуры (тикеты, AI, биллинг), жизненный цикл, раздел 12 — реестр всех 25 принятых решений. Изменения вносить только с повышением версии и пометкой пересмотренного решения.
2. **b24-api-mapping.md** — карта REST API Битрикс24: соответствие узлов спецификации методам, событиям и placement, сверено с официальной документацией apidocs.bitrix24.ru. Раздел 5 — что осталось проверить прототипами.
3. **work-plan-stage1.md** — план работ этапа 1 (запуск пилота): 6 фаз, 17–23 рабочих дня, критический путь и риски. Начинать с фазы 0 (прототипы рисков).

## Ключевые параметры проекта

- Стек: Node.js в Docker, Redis + BullMQ, без собственной СУБД (env + Redis + данные в Б24), сервер `support.bx-shef.by`
- Одно маркетплейс-приложение Б24, две части (клиентская + операторская), весь UI с нашего сервера
- GitHub: клиентские репозитории, GitHub App с минимальными правами, конвенция `ticket/{id}` + `Closes #N`
- Пилот: 3 клиента (2 × T&M, 1 × по согласованным оценкам), контур тикетов без биллинга и AI, 2–4 недели

## Порядок чтения для новых участников

Спецификация целиком → план работ → карта API (как справочник при разработке).
